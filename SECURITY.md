# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project:

1. **Do not** report security issues through public GitHub issues or pull requests.
2. Please send an email directly to **bernarddas1@gmail.com**.
3. Include:
   - A clear description of the issue and potential impact
   - Reproduction steps or proof of concept
   - Any suggested mitigations or patches

### Response Timeline

- **Acknowledgement**: Within 48 hours.
- **Assessment**: Within 7 business days with an assessment and remediation plan.
- **Release**: A fix will be published promptly, with appropriate credit given in the release notes.
